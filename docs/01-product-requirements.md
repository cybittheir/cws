# Требования продукта

## Назначение

Corporate Workspace — корпоративное web-приложение, объединяющее справочник контактов сотрудников и рабочий многослойный календарь. Инсталляция рассчитана на одну–пять компаний и до 200 пользователей.

## Компании

- Один пользователь может состоять в нескольких компаниях.
- Компания имеет название, логотип, домены/поддомены, часовой пояс, настройки и собственную структуру подразделений.
- Переключатель компании видят только системный администратор и пользователи с активным участием в двух и более компаниях.
- Пользователь с одной компанией видит только название и/или логотип текущей компании.
- Межкорпоративный обмен событиями, ресурсами и рассылками отключён по умолчанию.
- Включить межкорпоративный обмен может только системный администратор.

## Справочник

Карточка сотрудника содержит как минимум:

- фамилию, имя, отчество;
- фото;
- табельный номер;
- должность;
- основное и дополнительные подразделения;
- внутренний и мобильный телефон;
- рабочий и личный email;
- Telegram и Mattermost-ссылки;
- кабинет, рабочий адрес, город, часовой пояс;
- дату рождения;
- дату приёма, последний рабочий день и дату увольнения.

Год рождения не отображается обычным пользователям. Мобильный номер доступен коллегам. Личный email и ссылки на чаты показываются коллегам только с разрешения сотрудника. Уволенные сотрудники архивируются и видны только HR и администраторам.

Подразделения иерархические. Справочник группируется заголовками всех уровней подразделений; пустые подразделения скрываются. Поддерживаются поиск и фильтры по подразделению, должности, статусу и городу.

Постраничность включается по умолчанию при количестве записей свыше 50; лимит настраивается администратором компании. Город не показывается по умолчанию и автоматически появляется, если среди активных сотрудников компании есть два или более разных города. Вместо постоянной колонки города в справочнике выводятся доступные ссылки на Telegram/Mattermost.

## Массовый выбор и рассылка

- У каждого сотрудника есть чекбокс.
- У заголовков подразделений есть чекбокс и команда «Выбрать всех N сотрудников подразделения в текущем результате поиска».
- Выбор сохраняется при смене страниц и фильтров.
- Уволенные и заблокированные пользователи не могут быть получателями.
- Любой активный сотрудник может создавать рассылки.

## Темы

В системе предусмотрены четыре встроенные темы:

1. Синий туман — светлая.
2. Шалфей — светлая.
3. Песок — светлая.
4. Графит — тёмная.

Тема компании используется как значение по умолчанию. Пользователь может выбрать собственную тему; личная настройка имеет приоритет.
