# Развёртывание и резервное копирование

## Целевые варианты

- Linux;
- Windows;
- Docker;
- корпоративная сеть или VPN как основной сценарий доступа.

Интернет-доступ допускается позднее при корректной настройке HTTPS, reverse proxy, MFA, rate limiting и мониторинга.

## Базы данных

При развёртывании администратор выбирает один драйвер:

- SQLite — локальный пилот, небольшой single-server сценарий;
- PostgreSQL — рекомендуемый production-вариант;
- MySQL/MariaDB — при наличии корпоративного стандарта.

## Резервные копии

| Параметр | Правило |
|---|---|
| Периодичность | Ежедневно |
| Хранение | 30 дней |
| Расположение | Локальный каталог, отдельный от рабочей БД |
| Шифрование | Необязательно; включается в системных настройках |
| Ручной запуск | Доступен системному администратору |
| Журнал | Успех, ошибка, время, размер, путь, инициатор |
| Перед обновлением | Дополнительная резервная копия |
| Восстановление | Документированная процедура и периодическая проверка |

Для SQLite резервное копирование выполняется корректным механизмом SQLite backup, а не случайным копированием работающего файла. Для PostgreSQL в состав резервной копии включаются схема, данные, версия миграций и загруженные вложения.
