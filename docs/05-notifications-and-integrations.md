# Уведомления, импорт, экспорт и API

## Уведомления

Система выбирает канал доставки по политике компании и настройкам адресата. Планируемые каналы:

- email;
- Telegram;
- Mattermost;
- дополнительные каналы в будущем.

Пользователь настраивает разрешённые каналы, тихие часы и отказ от некритичных уведомлений. Критические системные сообщения регулируются политикой компании.

## Рассылки

Форма рассылки включает:

- тему;
- текст;
- вложения;
- ссылку на объект или событие;
- предпросмотр;
- шаблоны;
- опцию «Отправить себе» одновременно с остальными адресатами.

Хранятся автор, текст в момент отправки, список получателей, выбранный канал по каждому получателю, дата/время, статус доставки и ошибки. Необходимы журнал рассылок и аудит действий.

## Импорт и экспорт

Первая очередь импорта: CSV/XLSX с предпросмотром, сопоставлением колонок и отчётом ошибок. В дальнейшем: Active Directory/LDAP и 1С.

Экспорт:

- справочник: CSV/XLSX;
- календарь: CSV/XLSX, PDF и ICS;
- отпускные планы и журнал уведомлений: CSV/XLSX;
- аудит: экспорт для системного администратора.

## API

Нужен версионированный API `/api/v1/...` с API-ключами, областью прав, ограничением скорости, сроками действия ключей, аудитом вызовов и обязательной привязкой каждого ключа к компании.
