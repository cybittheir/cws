# SIP XML-адресная книга

## Назначение

Система генерирует актуальную внешнюю адресную книгу для SIP-телефонов по URL. Предпочтителен динамический XML-endpoint, а не вручную сформированный статический файл.

## Поддерживаемые профили

Первая очередь:

- Yealink Remote Phonebook: меню подразделений и XML-файлы списков;
- Generic flat XML: плоский список для совместимых устройств.

Позднее:

- Cisco XML Directory;
- Grandstream XML Phonebook.

## Контакты

В SIP-каталог включаются только активные сотрудники выбранной компании:

- ФИО;
- должность — при включённой настройке;
- основное подразделение;
- внутренний телефон;
- рабочий мобильный телефон — при включённой настройке.

Личные email, даты рождения, кадровые данные и скрытые личные контакты в XML не экспортируются.

Контакт выводится в основном подразделении. Дублирование в дополнительных подразделениях — настраиваемая опция.

## Безопасность

- HTTPS.
- Длинный случайный токен или Basic Auth.
- Раздельные ключи по компаниям/группам телефонов.
- Возможность отзыва ключа.
- IP allowlist корпоративной сети/PBX — при наличии инфраструктурной возможности.
- Rate limit и журнал запросов.
- `Content-Type: application/xml; charset=utf-8`.
- XML-экранирование всех пользовательских значений.

## Настройки компании

- Включение SIP-каталога.
- Формат XML.
- Плоская или иерархическая группировка.
- Номера для публикации.
- Отображение должности.
- Скопировать URL, создать или отозвать ключ.
- Журнал обращений.
