# Corporate Workspace

Корпоративное web-приложение: справочник сотрудников, многослойный рабочий календарь, годовое планирование отпусков, уведомления, бронирование корпоративных ресурсов и внешняя XML-адресная книга для SIP-телефонов.

Текущая поставка — **этап 0: спецификация и подготовка репозитория**. Рабочий Go-сервер на этом этапе ещё не добавлен.

## Назначение

Система рассчитана на одну–пять компаний в одной инсталляции и примерно до 200 пользователей. Один пользователь может состоять в нескольких компаниях и иметь разную роль в каждой из них. Межкорпоративный обмен по умолчанию отключён и может включаться только системным администратором.

## Технологический ориентир

- Backend: Go.
- Интерфейс: server-rendered HTML + JavaScript/AJAX.
- Базы данных при развёртывании: SQLite, PostgreSQL или MySQL/MariaDB.
- Рекомендуемая production-БД: PostgreSQL.
- Развёртывание: Linux, Windows или Docker.

## Версионирование

Проект использует семантическое версионирование:

- `v0.x.y` — разработка до первого стабильного релиза;
- `v0.1.0` — завершённый этап 1, запускаемый инфраструктурный каркас;
- `v0.2.0` — компании, пользователи, роли и рабочий справочник;
- дальнейшие версии соответствуют завершённым функциональным этапам.
